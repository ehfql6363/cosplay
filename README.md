# 오늘의 코스프레 캐스팅

어른과 아이가 섞인 모임에서 **코스프레 주제를 뽑고, 누가 어떤 캐릭터를 맡을지 정해 주는** 도구입니다.
놀이공원 나들이 전에 한 명이 폰으로 돌리고 다 같이 화면을 보는 상황을 기준으로 만들었습니다.

## 쓰는 순서

1. **명단** — 이름을 넣고 어른·아이만 정합니다. 쉼표나 줄바꿈으로 여러 명을 한 번에 넣을 수 있습니다.
2. **주제** — 룰렛을 돌려 오늘의 주제를 뽑습니다. 당첨 칸은 항상 12시에 멈춥니다.
3. **캐스팅** — 캐릭터가 배정됩니다. 카드마다 "이렇게 보이면 성공" 한 줄과 준비물, 난이도가
   붙고, 실제 코스프레 사진을 바로 찾아볼 수 있는 링크가 있습니다. 마음에 드는 카드는 고정하고
   나머지만 다시 뽑을 수 있고, 결과는 이미지로 저장하거나 메신저용 텍스트로 복사합니다.

## 만들 때 정한 것들

**서버를 두지 않았습니다.** 각자 로그인해서 쓰는 서비스가 아니라 한 명이 돌리고 함께 보는
도구라서, 서버를 붙이면 비용·인증·운영만 생기고 얻는 게 없습니다. 명단과 설정은 브라우저
`localStorage` 에 남고, 공유는 이미지 저장과 텍스트 복사로 합니다.

**배정은 랜덤 뽑기가 아니라 제약 만족 문제로 풉니다.** 단순히 섞어서 나눠 주면 아이에게 어른
전용 배역이 가거나 남자에게 여자 배역이 가는 사고가 납니다. `src/lib/assign.ts` 는 후보를 섞은
뒤 남은 후보가 가장 적은 사람부터 채우고(MRV) 막히면 되돌아갑니다. 덕분에 매번 결과가
달라지면서도 규칙은 항상 지켜지고, 배역이 모자라면 "어른 여자 캐릭터가 2명분 부족해요"처럼
어느 쪽이 부족한지 알려줍니다.

**성별은 하드 제약이되, 성별 없는 배역을 넉넉히 뒀습니다.** 모든 배역에 성별을 매기면 후보가
급격히 줄어 배정이 자주 실패합니다. 동물·마스코트·요정은 `ANY` 로 두어 누구나 맡을 수 있게
했습니다. 성별을 가리지 않고 섞고 싶은 모임은 설정에서 끌 수 있습니다.

**놀이공원 규정을 데이터에 넣었습니다.** 캐릭터마다 얼굴 전체를 덮는 탈·가면(`mask`)이나
무기류 소품(`prop`)이 필요한지 표시해 두고, 기본으로 그런 캐릭터를 후보에서 뺍니다.

`src/data/themes.test.ts` 가 **두 필터를 모두 켠 상태에서** 모든 주제가 어른 남2·여2, 아이
남2·여2 를 감당하는지, 그리고 조합마다 다시 뽑을 여유가 남는지 검사합니다. 캐릭터를
추가·수정하다 특정 주제가 못 쓰게 되는 일을 막아 줍니다.

> 파크별 코스튬 규정은 바뀔 수 있습니다. 이 앱의 필터는 참고용이니 방문 전에 해당 파크 공지를
> 확인하세요.

## 캐릭터 사진 넣기

`src/assets/characters/` 에 **캐릭터 이름 그대로** 파일을 넣으면 결과 카드 맨 위에 붙습니다.
코드는 고칠 필요가 없습니다.

```
src/assets/characters/피카츄.png
src/assets/characters/캡틴 아메리카.jpg
```

빌드할 때 Vite 가 폴더를 훑어 번들에 넣으므로 경로를 적을 일이 없고, 넣지 않은 캐릭터는
이미지 없이 지금처럼 렌더됩니다. 전부 채우지 않아도 됩니다. 넣어야 할 파일명 115개 전체
목록은 `src/assets/characters/README.md` 에 있습니다.

한글 파일명은 환경마다 유니코드 정규화 형태가 달라서(macOS 는 자모가 분리된 NFD 로 저장하는
일이 많습니다) 양쪽을 NFC 로 맞춘 뒤 비교합니다. 맥에서 만든 파일도 그대로 인식됩니다.

> 이 저장소는 공개되어 있고 캐릭터 이미지는 대부분 저작권이 있습니다. 어떤 이미지를 넣을지는
> 직접 판단해 주세요. 저장소를 비공개로 돌리는 것도 방법입니다.

## 주제·캐릭터 고치기

`src/data/themes.ts` 한 파일만 고치면 됩니다.

```ts
c('엘사', BOTH, F, 2, '온통 하늘색에 은발 땋은 머리 한 갈래. 반짝이는 긴 망토가 핵심', [
  '하늘색 드레스', '흰 머리 땋은 가발', '반짝이 망토',
]),
// 이름   담당 성별 난이도  이렇게 보이면 성공                      준비물   (선택) 'mask' | 'prop'
```

- **담당**: `BOTH` 는 어른·아이 모두, `ADULT` / `CHILD` 는 한쪽만 맡을 수 있습니다.
- **성별**: `M` / `F`, 그리고 `ANY` 는 성별을 가리지 않는 배역입니다. 동물·마스코트·요정처럼
  의상만 보면 성별이 드러나지 않는 쪽에 쓰세요. 이런 배역이 넉넉해야 성별 맞춤을 켜도
  후보가 마르지 않습니다.
- **난이도**: `1` 집에 있는 옷으로 / `2` 소품 한둘 필요 / `3` 공들여야 함.
- **이렇게 보이면 성공**: 준비물 목록만으로는 "그래서 어떻게 보여야 하는데?" 가 안 풀립니다.
  색과 실루엣, 그리고 그것만 맞으면 알아보는 한 가지를 한 줄로 적어 주세요.

주제를 통째로 추가하려면 `DRAFTS` 배열에 항목을 하나 더 넣으면 룰렛에 자동으로 들어갑니다.
룰렛 칸에 들어가야 하니 주제 이름은 다섯 글자 안쪽이 좋습니다.

## 개발

```bash
npm install
npm run dev     # 개발 서버
npm test        # 배정 알고리즘 · 주제 데이터 검사
npm run build   # 타입 검사 후 프로덕션 빌드
```

`main` 에 푸시하면 GitHub Actions 가 테스트·빌드 후 GitHub Pages 로 배포합니다
(`.github/workflows/deploy.yml`). 저장소 **Settings → Pages → Source** 를 **GitHub Actions**
로 한 번 바꿔 주어야 첫 배포가 됩니다.

Pages 는 `/cosplay/` 경로로 서빙되므로 `vite.config.ts` 의 `base` 가 거기에 맞춰져 있습니다.
다른 곳에 올릴 때는 `BASE_PATH=/ npm run build` 처럼 덮어쓰면 됩니다.

## 구조

```
src/
  types.ts              구성원·캐릭터·주제 타입
  data/themes.ts        주제와 캐릭터 목록 (여기만 고치면 됩니다)
  lib/assign.ts         제약을 지키는 랜덤 배정
  lib/share.ts          결과 텍스트·이미지 내보내기
  lib/storage.ts        localStorage 연동 state
  components/           명단 · 룰렛 · 결과 화면
```
